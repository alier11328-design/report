# AI 测试示例截图

运行下面命令可以重新生成一套本地测试图：

```bash
python3 scripts/generate_example_images.py
```

生成目录：

```bash
examples/ai-sample-screenshots/
```

推荐对应关系：

- `course-plan.html`
  - 上传 `course-plan-outline.png`

- `period-feedback.html`
  - `AI 识别排课`：上传 `period-feedback-schedule.png`
  - `AI 识别反馈`：上传 `period-feedback-feedback-chat.png`

- `final-report.html`
  - `AI 识别填充`：上传
    - `final-report-grade-summary.png`
    - `final-report-teacher-feedback-chat.png`

- `review-report.html`
  - `AI 识别原因分析`：上传 `review-report-reason-chat.png`
  - `AI 识别过程复盘`：上传 `review-report-process-timeline.png`
